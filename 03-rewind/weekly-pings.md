## Query

```sql
SELECT date_trunc('week', sent_at)::date AS week,
       CASE WHEN sent_at < timestamp '2026-08-12' THEN 'before' ELSE 'after' END AS period,
       responder,
       count(*) AS pinged,
       count(*) FILTER (WHERE outcome = 'taken') AS taken
FROM rook.pings
WHERE sent_at >= '2026-06-01'
GROUP BY 1, 2, 3
ORDER BY 1, 2 DESC, 3;
```
